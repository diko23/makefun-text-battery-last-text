Entry for the make.fun bounty [The Battery's Last Text to Its Charger](https://make.fun/bounty/u-alven-the-battery-s-last-text-to-its-charger-4278cfab).

## About the entry

A single-line plain-text entry written from the perspective of a phone battery running out of patience after waiting on its charger all day, turning the final moments at 1% into a spiteful, deliberate refusal to crawl back behind the nightstand.

## Run it

The grader executes the TypeScript entrypoint directly with Node 22:

```bash
node main.ts
```

By default it writes the UTF-8 entry text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when `MAKEFUN_OUTPUT_DIR` is set) with file mode `0644`, produces no stdout on success, and exits non-zero on failure.
